# Game 3 – Vanilla-Boote (Variante A)

- Keine ItemDisplay-Rennbootverkleidungen mehr.
- Normale Eichenboote mit farbigem Teamnamen und Teamnummer.
- Teamfarbige Leuchtkontur per Scoreboard-Team.
- Dezente Schneepartikel bei Bewegung.
- Start/Checkpoint/Ziel, 7-Minuten-Limit, Punkte und Wand bleiben aus der letzten Version erhalten.
- Kein neues Resourcepack erforderlich. Altes Buzzer-Resourcepack kann bleiben.

## Installation

Quellcode ins **Gameshow**-Repository hochladen, GitHub Actions bauen lassen, JAR ersetzen und Server neu starten. Danach `/wg tp game 3` und `/wg game3 start`.

**Hinweis:** Nicht lokal kompiliert; Maven ist in der Arbeitsumgebung nicht verfügbar. Bitte GitHub-Actions-Build prüfen.
