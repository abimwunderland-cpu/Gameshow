# Game 3: Farbige Rennboot-Aufbauten

Das Plugin erzeugt zu jedem normalen Rennboot einen farbigen 3D-Aufbau als ItemDisplay. Die Bootssteuerung bleibt Vanilla. Die sichtbare Holz-Basis wird NICHT unsichtbar: dies ist ein farbiger Rennboot-Aufbau, kein vollstaendiger Ersatz des Vanilla-Boots.

## Installation
1. Dieses Source-ZIP in das **Gameshow**-GitHub-Repo laden (nicht Junkiecraft) und per GitHub Actions kompilieren.
2. Das neue Resourcepack `WolfsfellGameshow-Buzzer-und-Rennboote.zip` auf dem Minecraft-Client installieren, oberhalb anderer Packs. Das alte Buzzer-Pack durch dieses ersetzen (alle Buzzer und Sounds sind enthalten).
3. Neue Plugin-JAR auf Paper 1.21.11 installieren und Server neu starten.
4. Mit `/wg tp game 3` werden die Boote mit farbigen 3D-Aufbauten erzeugt.

Hinweis: Nicht in Minecraft getestet. Farben werden anhand der Teamfarbe aus dem Plugin gewaehlt. Das Modell ist eine erste funktionsfaehige Geometrie, kein High-End-Rennboot.
