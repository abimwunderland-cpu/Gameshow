# 3D-Buzzer-Modelle (Paper 1.21.11)

1. Neue Plugin-Source in GitHub hochladen und per Actions bauen.
2. Die SEPARATE ZIP `WolfsfellGameshow-Game1-3D-Buzzer-Resourcepack.zip` als Ressourcenpaket verwenden (ZIP nicht entpacken).
3. Teamfarben über vorhandene Teamfarben-Konfiguration festlegen. Das Plugin verwendet RED, BLUE, GREEN, YELLOW, ORANGE, PINK, CYAN, WHITE oder PURPLE.
4. Gespeicherte Stone Buttons bleiben erhalten. Das Modell ist ein rein visuelles ItemDisplay ohne Klick-Hitbox.
5. Test: Server neu starten, Ressourcenpaket aktivieren und Button anklicken.

Die Modelle erscheinen automatisch über den bereits gespeicherten Buttons. Bei wandmontierten Buttons kann die Position optisch abweichen.

Hinweis: Source wurde nicht kompiliert oder im Spiel getestet.
